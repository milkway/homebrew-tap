# milkway's Homebrew tap

```sh
brew install milkway/tap/rxform
brew install milkway/tap/dune
```

Formulae here:

| Formula | Description |
|---|---|
| [`rxform`](Formula/rxform.rb) | Convert [XLSForm](https://xlsform.org) spreadsheets to ODK XForm XML — [milkway/rxform](https://github.com/milkway/rxform) |
| [`dune`](Formula/dune.rb) | Circuit simulator derived from Berkeley SPICE3f5, the `dune` command — [milkway/dune](https://github.com/milkway/dune). Conflicts with homebrew-core's `dune` (the OCaml build system): install it as `milkway/tap/dune` |
